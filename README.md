# YARA-ThreatIntel-Toolkit
Cheat sheet for malware analysis and threat intelligence using YARA, Loki, THOR Lite, YAYA, Fenrir, Cuckoo Sandbox, Volatility, Wireshark, and VirusTotal. Includes real-world detection rules, IOC scans, memory forensics, and behavioral analysis — with actionable commands and output examples for blue teamers and SOC analysts.
